# 法法菈桌寵

以《星痕共鳴》法法菈為主角的非官方 Windows 桌寵。
打字時她會跟著跳躍，停下後會靜候、打盹，最後上床睡覺。

## 下載與使用

前往 [Releases](https://github.com/forked0/FafalaDesktopPet/releases)，
下載 `FafalaPet_V4.3.zip`，解壓縮後執行 `FafalaPet.exe`。

左鍵拖曳可移動桌寵，滾輪可調整大小。
右鍵點桌寵，或點 Windows 通知區的法法菈頭像，即可開啟選單。

|　　功能　　| 介紹 
|　　關於　　| 查看免費使用、轉載分享、禁止營利及角色權利歸屬聲明。可按「關閉」、右上角 × 或 `Esc` 關閉視窗。
|　切換桌寵　| 選擇要顯示的角色，目前收錄法法菈。 
|　桌寵大小　| 提供 50%、75%、100%、125%、150%、200% 六種大小，預設 100%。
|　打盹倒數　| 設定從靜候到休息的等待時間，可選 10、15、20、25、30 秒，預設 15 秒。
|　愛睏倒數　| 設定從休息到睡眠的等待時間，可選 1、3、5 分鐘，預設 1 分鐘。 
|　　靜候　　| 手動開啟永久待機，法法菈會持續播放呼吸、眨眼動畫。即使打字也會保持靜候，重新啟動後仍會保留。 
|　　休息　　| 讓法法菈立即打盹，手動休息期間會暫停自動倒數。 
|　　睡眠　　| 讓法法菈直接上床，循環播放緩慢呼吸的睡眠動畫。 
|　連續跳躍　| 勾選後會持續跳躍，取消勾選即可回到靜候。
|　關閉桌寵　| 結束程式，同時關閉通知區圖示。
